UniTrade – A Campus Marketplace

 Project Description

UniTrade is a campus-based online marketplace designed specifically for university students. It provides a convenient platform where students can buy and sell items within their university community.

Students can create accounts, post products with details such as title, category, price, description, image, and preferred pickup location. They can also browse and search for products, view product details, contact sellers, and manage their own listings.

An administrator can monitor users and listings, review reported content, remove inappropriate listings, and suspend student accounts when necessary.

Main Features:

### Student
- Student registration and login
- Profile management
- Create product listings
- Edit and delete own listings
- Browse and search products
- View product details
- Contact seller
- Select preferred pickup location
- Mark items as sold
- Report inappropriate listings

### Administrator
- Admin login
- View users and listings
- Review reported listings
- Remove inappropriate listings
- Suspend student accounts
